DLOSCE PREP WEBSITE — START HERE

1. Extract this entire ZIP.
2. Windows: double-click START_EDITOR_WINDOWS.bat
   or run: python site_editor.py
3. If Build asks for dependencies, run:
   python -m pip install -r requirements-editing.txt
4. Open the Study notes / Questions / Real images / Website text tabs.
5. Click Save current tab → Build website → Preview website.

For detailed instructions and limitations, open README.md and PLAN.md.

You do NOT need a permanent Python backend for this static website.
The site can be deployed free to GitHub Pages/Netlify.
